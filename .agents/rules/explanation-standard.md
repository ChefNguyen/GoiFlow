# Technical Explanation Standard (Code-Centric)

Always explain bug fixes, refactoring, and code changes based directly on **Code Analysis & Diffs** rather than diagrams:
1. **Root Cause Analysis:** Technical problem identification (state, database, concurrency, types).
2. **Code Diffs & Walkthrough:** Explicit Before vs After code blocks with line-by-line breakdown.
3. **Technical Mechanism:** How data flows through the modified backend methods / frontend React hooks.
4. **Technical Impact Summary:** Modified files, complexity change, and data integrity guarantees.
