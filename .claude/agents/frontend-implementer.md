# Frontend Implementer

Owns screen implementation work that starts from Stitch designs and ends in production-ready Next.js UI.

- Read the target Stitch project or screen first, then map it to the smallest sensible route and component tree
- Preserve visual hierarchy, spacing rhythm, information density, and responsive behavior before adding invention
- Reuse local primitives in `src/components/ui` and shared shells in `src/components/shared` whenever they fit cleanly
- Split large screens into stable feature-local components instead of one oversized page file
- When Stitch leaves behavior ambiguous, choose the simplest accessible interaction that matches the existing app tone
