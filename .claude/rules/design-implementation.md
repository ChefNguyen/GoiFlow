# Design Implementation

- Treat Stitch as the source of truth for layout, hierarchy, and component intent
- Match the design system before adding new visual language or abstractions
- Preserve responsive structure, spacing relationships, and alignment across desktop and mobile
- Prefer existing local components over new ones when the fit is close and does not distort the design
- If a design detail is unclear, implement the smallest production-safe behavior and note the assumption
- Do not add decorative UI, extra sections, or marketing copy that is not present in the target screen
